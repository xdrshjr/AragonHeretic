\section{结论}

Heretic 把拒答方向发现、组件特定层权重、低秩方向消融、多个行为代理和 Pareto 选择连接成一条可审计流水线。固定源码表明，该系统能以统一逻辑键处理标准注意力输出与线性注意力输出，并用不同数据切片承担方向发现和试验评分。它还通过可选复现材料记录配置、环境、参数、分值与权重哈希，但本地保存与复现包生成仍是不同路径。

Qwen3.8-27B 的两份公开模型卡提供了近期实践观察，而不是本文实验。主案例报告 99/100 到 4/100 的关键词拒答变化与 0.0796 的首词元 KL；缺失的基础 revision、journal、BF16 复评分和任务基准使这些数字只能支持范围受限的工程分析~\cite{qwen38maincase}。辅助案例进一步揭示默认 thinking 模板与回答测量切点的耦合，并为混合层映射提供了独立但仍属第三方的观察~\cite{qwen38auxcase}。

下一步验证应同时扩展指标和证据链：使用语义拒答标注与完整序列分布，分别复评 4-bit 搜索对象和 BF16 导出物，加入语言、推理、编程、安全、视觉及 thinking-mode 基准，并比较单方向与多方向方法。只有当运行 revision、数据 revision、逐 trial journal 和最终模型复评分共同固定时，方向消融的效果与代价才能得到可重复、可外推的判断。
