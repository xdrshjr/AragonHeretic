# 审稿人应对策略

## 目标会议：自定义 IEEE 双栏技术补充（7--9 页）

## 预估审稿人画像

### 典型审稿人类型

1. **领域专家**：检查拒答几何、SOM 协议与源码公式是否准确。
2. **广义 ML 研究者**：关注无实验稿件的贡献边界和非凸论证。
3. **严格型审稿人**：检查引用、匿名、版本冻结、可复现性和过度主张。

## 打动审稿人的策略

### 新颖性论证

强调“理论—实现桥接”：公式不是从概念标签倒推，而是逐行对应固定源码；跨范式比较使用共同坐标，避免无控制变量排行榜。

### 实验说服力

不伪造主实验。以三权分立源码核验、数学反例、同行评议文献边界和可执行统一协议作为当前证据；把需要模型运行的问题明确列为未来实验。

### 写作策略

每段首句给结论，随后给公式或证据边界；不用“显著、领先、保证”等超出证据的词。图表承担流程和结构比较，正文解释关键差异。

## 常见拒稿原因预防

| 拒稿原因 | 预防措施 | 检查时间 |
|---------|---------|---------|
| 创新性不足 | 把源码重述提升为公式、反例、复杂度、证据框架 | 写作统稿 |
| 实验不充分 | 明示论文类型和证据上限，不设置伪实验节 | 摘要与终审 |
| 写作质量差 | IEEE 双栏实编译，修复 overfull 与图表可读性 | 每轮构建 |
| 引用遗漏 | BibTeX 双向扫描；Optuna、SOM、LBFGS、LoRA 逐项引用 | 文献终审 |
| 与已有工作对比不足 | 三范式表 + 几何图 + 不可比性段 | Sec. 4 审核 |
