## 最终共识

### 核心创新点（排序后）

   - 简述：重建冻结模块 I/O、三项损失、全矩阵/低秩参数化、内层 L-BFGS 与外层搜索。
   - 代码依据：`src/<pkg>/model.py:578-799,934-1058`；`src/<pkg>/utils.py:238-243`。
2. **从单方向到多方向再到直接映射的结构比较坐标** — 新颖度：中高，影响度：中
   - 简述：比较决策变量、数据锚点、干预算子和搜索对象，不建立跨协议数值排名。
   - 代码依据：`src/<pkg>/main.py:455-700`；文献依据：Arditi2024、Piras2026。
3. **理论声明与实现边界的证据分层审计** — 新颖度：中，影响度：高
   - 简述：澄清一般非凸/非光滑、任意秩的限定语义、冻结代理、偏置、MoE 前置条件和低秩一致性。
   - 代码依据：固定提交的 E01--E10 与已通过复审的分析文件。

### 论文技术贡献定位

论文是当前主稿的独立批判性技术补充，不是新增模型级性能论文。其贡献是把演化中的公开源码原型转换成可核对的数学对象，并用同行评议的单方向与 SOM 多方向文献建立机制参照和实验缺口。

### 与 SOTA 的差异化描述

差异只建立在参数化对象上：单方向方法删除一个显式分量；SOM 方法从 16 个原型方向中搜索 2--7 个有序投影；源码矩阵法直接优化模块映射。没有统一模型、数据、判别器、解码与搜索预算，因此不允许效果排序。

### 数学形式化共识

总损失为良性输出均方保持与目标行为输出的 kNN 拉近/推远组合。动态邻居选择使目标一般非凸，邻居交换和零距离使其一般非光滑；经典光滑 L-BFGS 或全局最优保证不能由源码推出。“任意秩”只表示全矩阵路径没有显式低秩更新约束。
