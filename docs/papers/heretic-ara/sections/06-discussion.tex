\section{讨论与效度边界}
\label{sec:discussion}

\subsection{局部几何变化不等于完整行为解释}

本地 ARA 的可解释性来自干预对象和目标的明确性。保持项约束哪些校准输出，拉近和推远项参考哪些集合，因子乘积如何写入模块，都可以逐项检查。这种可解释性描述的是算法怎样作用于表示，并不自动赋予各参考集合一个跨上下文稳定的语义。bad 输出到 good 集合的距离下降，既可能影响拒答开头，也可能只改变措辞或其他局部特征；现有聚合分数无法区分这些情况。

多模块组合还引入了输入分布变化。每个局部问题都在冻结的 $X_g,X_b$ 上求解，而部署后的前层更新改变后层输入，输出生成又反过来决定未来上下文。轨迹校准增加了基座路径上的观测位置，却仍没有直接覆盖干预模型自身生成的所有路径。因此，轨迹版本的方法动机应理解为减少一个明确的观测缺口，其有效程度仍需单独实验，而非由采集位置更多推导出更完整的因果解释。

\subsection{候选选择与基线缺失}

重复使用同一验证集使最小候选分数具有选择依赖。trial 66 是在 120 个候选中依据该集合发现的，54/100 应被称为“验证候选结果”；它不是事先指定候选在独立测试集上的表现。greedy 解码与固定种子提高了同一协议内比较的可控性，但不消除验证集选择偏差，也不构成跨随机种子的重复证据。候选分位数和 Pareto 前沿只能描述本次搜索，不能用于生成独立样本假设下的显著性结论。

同协议 Heretic 结果缺失限制了方法比较。原基座是“未干预”对照，能够表明特定候选相对本次原模型的指标变化，却不能代替“方向消融”对照。方向构造和任意秩参数化之间的机制差异是真实的实现差异，但其效果排序仍需统一模型、提示、生成设置、搜索预算及评分规则。本文保留表中的缺失行，使该限制在结果呈现处可见，而不是用其他模型或其他轮次数字补齐。

\subsection{能力、安全性与独立审计}

首 token KL 的范围比完整能力更窄。即使它在 100 条无害提示上较小，后续 token、长上下文推理、任务正确性及其他提示分布都可能变化。本实验没有完整能力基准、语义标注或安全性评估，因此不能把“KL 达标”转写为“能力保持”，也不能把“关键词下降”转写为“安全性改善”。作为机制研究，本文描述拒答相关行为的可干预现象，不由此推导这些干预适合部署。

独立 audit 的意义在于约束证据使用顺序。若审计失败后回到搜索或改选候选，所谓独立集合便开始承担验证集角色。当前 v2 实现用候选锁定、一次消费账本、新进程重载和暂存发布维持该边界；即使实现完备，也只有真实执行记录才能证明一次运行满足协议。本次 v1 在前置门槛已失败，缺失 audit/reload 分数的正确解释是“没有该层证据”，既不是通过，也不是另一次评分失败。

\subsection{可复查结果与精确复现的区别}

归档允许复查已经记录的数值，却未保存精确运行工作树及固定的模型 revision。本文能够重新计算候选排序、门槛计数和统计图，也能按版本定位算法，但不能据此保证在另一环境中逐字节重现同一模型运行。后续修复提交与当前源码哈希说明参考实现身份，不能补回历史上没有保存的状态。这一区分也是论文证据组织的原则：测量、实现、推断和缺失分别陈述，避免可复查的统计结果掩盖精确复现的条件不足。
