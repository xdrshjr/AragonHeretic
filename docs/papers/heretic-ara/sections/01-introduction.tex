\section{引言}
\label{sec:introduction}

安全对齐语言模型的拒答行为能够被内部表征干预显著改变。单方向研究以有害与无害提示的表征均值差为核心，报告一个方向在多个聊天模型上介导拒答，并把投影折叠为秩一权重编辑\cite{arditi2024refusal}。随后，SOM 多方向方法用有害表征的局部原型构造方向池，再自动搜索若干方向的有序投影；该工作在其同行评议协议内报告了相对单方向基线的改进\cite{piras2026som}。这些方法虽从一维走向多维，却仍把方向保留为显式中间变量。

公开 ARA 原型采用另一条路线：缓存目标线性模块的输入与输出，然后直接优化模块映射\cite{ara2026source}。本文所称\emph{局部邻域映射}，指用正常输出点集和原目标输出点集约束候选输出的位置；它没有质量守恒或样本耦合约束，因而不是最优传输。无显式方向也只表示不预先构造全局表示向量，并不否认梯度方向、低秩子空间或数值搜索方向的存在。

本次修订增加本地 point-v1 的实现分析与一份冻结运行记录\cite{ara2026localv1,ara2026archive}。三个版本必须分开：上游原型保留硬 $k$NN、全矩阵或低秩路径及分段评分；point-v1 改为软邻域和缓存输出增量，具有一次模型搜索记录；当前 trajectory-v2 增加多位置缓存及验收控制，但指定归档没有其效果结果\cite{ara2026localv2}。表~\ref{tab:ara-version-comparison} 固定全文的版本用语，避免将旧缺陷归于本地实验，或把后续代码当作已验证改进。

本文回答三个问题：冻结模块目标具体约束什么，如何对应本地部署映射；一次搜索完成是否意味着候选通过验收；以及现有记录能支持多强的机制解释。归档中的 120 个试次均为 COMPLETE，但最低 Keywords 仍为 0.54，高于 0.10 门槛；验收结果为失败。工程流程完成与效果不达标同时成立，是本文需要解释的事实。

本文的贡献有三点：
\begin{enumerate}
  \item 保留上游原型的源码一致推导与非凸反例，并形式化本地 point-v1 的归一化软邻域目标、因子重置、规范化和数值校验，明确两者差异。
  \item 基于经哈希校验的原始事件记录，重算全部 120 个候选、分位数、Pareto 集与联合门槛，报告单模型、单次自适应验证搜索的负结果。
  \item 建立方向投影与直接映射的结构比较及分层证据边界，将历史源码、本地观察和未实测的 trajectory-v2 控制分别归属。
\end{enumerate}

本次工作重算已记录标量，没有重新加载模型生成响应。验证集被全部候选反复使用，120 次评估不是 120 次独立重复实验；没有候选被选中，也没有审计、重放或复载评分。运行记录未固定完整工作树、模型修订及全部包版本，因此聚合可复核不等于模型实验可完全重建。本文据此分析失败边界，不做跨协议效果排名，不把词汇代理或首词元 KL 升级为语义安全与能力结论。
