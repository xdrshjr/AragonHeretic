\begin{abstract}
拒答消融从显式方向投影扩展到直接优化 Transformer 模块映射，但参数自由度不能替代行为证据。本文区分上游 ARA 原型、本地 point-v1 适配和尚无效果记录的 trajectory-v2，重建前两者的数学目标与实现边界。上游原型使用硬近邻及负距离项；本地适配使用缓存输出上的秩至多 128 的增量、尺度归一化软邻域、非负间隔惩罚、完整因子重置和数值一致性检查。我们从冻结日志重算一次 Qwen3.8-27B 验证集自适应搜索：120 个试次全部完成，最低关键词命中率由基线 1.00 降至 0.54，对应首词元 KL 约 0.089975；全部候选未通过联合效果门槛，没有通过验收的适配器。该观察不能证明语义拒答下降、通用能力保持或机制因果性。本文贡献限于版本一致形式化、结构比较与失败实验分析；运行时工作树及模型版本记录不完整，日志聚合复核也不等同于重新运行模型或独立复现。
\end{abstract}
